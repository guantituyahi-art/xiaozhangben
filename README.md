# 小账本 · AI 与生活

一个给手机浏览器用的小记账本。重点解决两件事：

1. 看清每个月在 **AI 工具、开发相关** 上花了多少钱；
2. 给 **日常生活** 设一个月预算，花超了能一眼看出来。

纯静态网页，不需要注册账号、不需要服务器、数据只存在你自己的手机浏览器里。

**在线地址（已部署到 GitHub Pages，HTTPS）：**

```
https://guantituyahi-art.github.io/xiaozhangben/
```

手机浏览器打开这个网址 → 添加到主屏幕，就能像 App 一样使用。也可以直接扫描二维码：

![小账本二维码](screenshots/qr.png)

## 安卓 App 安装包（推荐）

安卓手机（荣耀 / 华为 / 小米 / OPPO 等）建议直接装 App 版：**数据存在 App 自己的存储里，不受 Chrome/浏览器清理影响**，退出后台、重启手机都不会丢。

手机浏览器打开这个下载地址：

```
https://guantituyahi-art.github.io/xiaozhangben/download/xiaozhangben-1.0.3.apk
```

或直接扫码下载：

![App 安装包二维码](screenshots/apk-qr.png)

安装步骤：

1. 用手机浏览器打开下载链接（微信里打开可能被拦截，建议复制到 Chrome/系统浏览器）；
2. 下载完成后点「安装」；系统如果提示“禁止安装未知应用”，按提示允许当前浏览器安装；
3. 如果 Play 保护/安全中心提示“未识别应用”，选择「仍要安装」；
4. 安装完成，桌面出现「小账本」图标，打开即用。

说明：

- **App 版和浏览器版的数据是分开的**，换到 App 后是空账本；
- App 里导出的备份保存在手机「下载/小账本」文件夹，可以随时导入恢复；
- 以后更新 App 直接覆盖安装即可，数据会保留（升级包需同一签名，由我这边提供）。

## 功能一览

- **3 秒记一笔**：输入金额 → 点分类 → 保存。备注和日期可选。
- **两类预算**：AI / 开发、生活各设一个月度预算，显示进度、剩余和日均可用金额，超支变红。
- **明细**：按月查看，按分类筛选，点任意一条可修改或删除。
- **统计**：本月 AI/开发 vs 生活的占比、分类排行、近 6 个月趋势。
- **数据备份**：导出 `.json` 备份、导出 `.csv` 表格（Excel 可打开）、从备份导入、清空记录。
- **离线可用**：安装到桌面后，断网也能记账（数据本来就在本机）。
- **月份切换**：可以回看往月，也可以补记上个月的账。

## 三、数据怎么存、怎么备份

- 数据保存在**当前手机、当前浏览器**的 localStorage 里，不上传任何服务器。
- 因此：**清理浏览器数据、卸载浏览器、换手机，数据会丢**。
- 建议每月导出一次备份：设置页 → 「导出备份文件（.json）」，把文件存到网盘或电脑。
- 换新手机：在新手机打开小账本 → 设置 → 「从备份文件导入」→ 选择备份文件。
- 清空全部记录只删记录，**预算设置会保留**。

## 四、常见问题

**Q：换手机/换浏览器数据会同步吗？**
不会。当前版本没有云端同步，靠导出/导入备份迁移。

**Q：为什么预算每月自动重置？**
预算按自然月统计。设置里的金额是「每月预算」，每个月 1 号自动按新月份重新计算，不用手动清零。

**Q：可以加自定义分类吗？**
第一版分类是固定的（AI/开发 5 类 + 生活 8 类）。如果常用分类不够，告诉我，可以加。

**Q：部署后更新了文件，手机上还是旧版本？**
Service Worker 采用「联网优先、离线回退」：正常联网打开就会拿到最新文件，首次可能需要刷新一两次。如果仍显示旧版，把 `sw.js` 里的 `CACHE_NAME` 改成新版本号（例如 `xiaozhangben-v1.0.4`）再重新部署，可以强制清掉旧缓存。

**Q：数据存在哪里？安全吗？**
只存在本机浏览器，只有你能看到；没有密码锁，手机借给别人时请注意。

## 五、给维护者（技术说明）

- 无构建步骤，直接改文件即可；`app.js` 是唯一业务逻辑文件，使用 IIFE + 事件委托渲染。
- 数据模型：

```json
{
  "version": 1,
  "settings": { "aiBudget": 300, "lifeBudget": 1500, "lastCat": "ai-tools" },
  "txs": [
    { "id": "uuid", "date": "2026-11-10", "cat": "ai-tools", "amount": 20, "note": "Claude 订阅", "createdAt": 1699999999999 }
  ]
}
```

- 分类定义在 `app.js` 顶部的 `CATEGORIES` 数组里，新增分类只需加一行（id 不要重复）。
- 预算统计按 `date` 的 `YYYY-MM` 归月；金额内部按分计算，避免浮点误差。
- 导入时会校验并清洗数据，未知分类归入「其他」；重复 id 会重新生成。
- `sw.js` 采用「联网优先、离线回退」策略；`CACHE_NAME` 用于强制清理旧缓存，重大更新时改一个版本号即可。
- 测试过的流程：录入、编辑、删除、预算超支、月份切换与补记、导入覆盖、清空、导出、刷新持久化、断网打开。
